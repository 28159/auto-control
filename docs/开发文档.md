# 开发文档

## 开发环境搭建

### 前置条件

- Windows 10/11
- .NET 9 SDK
- Visual Studio 2022 (推荐) 或 VS Code + C# 扩展

### 获取代码

```bash
git clone <repository-url>
cd WeChatAutomation
```

### 编译

```bash
dotnet build
```

### 运行

```bash
dotnet run --project src\WeChatAutomation.App
```

## 项目结构

### WeChatAutomation.Core (类库)

核心逻辑，不依赖 UI 框架。

| 目录 | 说明 |
|------|------|
| `Native/` | Win32 API P/Invoke 封装 |
| `Recording/` | 录制与回放引擎 |
| `Logging/` | 日志系统 |

### WeChatAutomation.App (WPF 应用)

用户界面，引用 Core 项目。

| 文件 | 说明 |
|------|------|
| `MainWindow.xaml` | 主窗口 XAML 布局 |
| `MainWindow.xaml.cs` | 主窗口代码逻辑 |

### 常见问题

**Q: 钩子不工作**
A: 确保以管理员权限运行，或检查杀毒软件是否拦截。

**Q: 回放点击位置偏移**
A: 检查 DPI 设置，确保录制和回放时的缩放比例一致。

**Q: 文本输入乱码**
A: 使用剪贴板粘贴方式（默认），不要使用 SendKeys。
