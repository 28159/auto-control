## 核心组件

### 1. 全局钩子系统

**MouseHook** - 捕获全局鼠标点击事件

```csharp
// 使用方式
var mouseHook = new MouseHook();
mouseHook.ClickCaptured += OnClick;
mouseHook.StartCapture();  // 开始捕获
mouseHook.StopCapture();   // 停止捕获

// 点击回调
private void OnClick(object sender, MouseClickInfo info)
{
    // info.X, info.Y - 坐标
    // info.ElementName - UIA 元素名称
    // info.ClassName - 控件类名
}
```

原理：
- 使用 `SetWindowsHookEx(WH_MOUSE_LL, ...)` 安装全局鼠标钩子
- 通过 `WindowFromPoint` 获取点击的窗口句柄
- 使用 `AutomationElement.FromPoint` 获取 UIA 元素信息
- 通过进程 ID 排除自身窗口

**KeyboardHook** - 捕获键盘事件

```csharp
var keyHook = new KeyboardHook();
keyHook.HotKeyPressed += OnHotKey;    // F9/F10/F11 快捷键
keyHook.KeyRecorded += OnKeyRecorded; // 录制键盘操作
keyHook.StartCapture();
```

原理：
- 使用 `SetWindowsHookEx(WH_KEYBOARD_LL, ...)` 安装全局键盘钩子
- 通过 `GetKeyState` 检测 Ctrl/Alt/Shift 修饰键状态
- 区分可打印字符（累积为文本）和特殊键（单独记录）

### 2. 录制器 (ActionRecorder)

**两种录制模式：**

| 模式 | 说明 |
|------|------|
| Continuous | 自动捕获所有鼠标点击 |
| StepByStep | 每次点击后按 F10 确认才记录 |

**核心逻辑：**

```csharp
public class ActionRecorder
{
    private readonly MouseHook _mouseHook;
    private readonly KeyboardHook _keyHook;
    private readonly List<RecordedAction> _nodes;
    private RecordMode _mode;
    
    // 开始录制
    public void Start(RecordMode mode) { ... }
    
    // 停止录制
    public void Stop() { ... }
    
    // StepByStep 模式确认
    public void ConfirmStep() { ... }
    
    // 手动添加步骤
    public void AddManual(ActionType type, string param, string name) { ... }
}
```

**文本输入合并：**
- 连续输入的字符会自动累积到文本缓冲区
- 超过 500ms 无输入或遇到特殊键时自动 flush 为一个 TypeText 步骤

### 3. 回放器 (ActionPlayer)

```csharp
public class ActionPlayer
{
    // 回放步骤列表
    public async Task Play(List<RecordedAction> nodes) { ... }
    
    // 设置目标窗口（阅读功能用）
    public void SetTargetWindow(IntPtr hwnd) { ... }
    
    // 停止回放
    public void Stop() { ... }
}
```

**支持的操作类型：**

| ActionType | 执行方式 |
|------------|----------|
| Click | SetCursorPos + mouse_event |
| TypeText | 剪贴板粘贴 (Ctrl+V) |
| SendKeys | keybd_event 模拟按键 |
| Wait | Task.Delay |
| Copy | Ctrl+C |
| Paste | Ctrl+V |
| InsertText | 剪贴板粘贴 |
| Screenshot | Graphics.CopyFromScreen |
| OpenApp | Process.Start |
| WaitForApp | 循环检查 Process.GetProcessesByName |
| ReadContent | UIA AutomationElement 递归提取文本 |
| ScrollRead | 滚动 + ReadContent |
| Scroll | mouse_event MOUSEEVENTF_WHEEL |

## 数据模型

### RecordedAction

```json
{
  "NodeId": "a1b2c3d4",
  "Order": 1,
  "ActionType": "Click",
  "Name": "点击按钮",
  "ClassName": "Button",
  "ElementName": "确定",
  "AutomationId": "btnOk",
  "ControlType": "Button",
  "X": 500,
  "Y": 300,
  "Parameter": "",
  "DelayMs": 300,
  "IsEnabled": true
}
```

### RecordingFile

```json
{
  "Name": "我的脚本",
  "Description": "",
  "CreatedAt": "2025-01-01T00:00:00",
  "Actions": [...],
  "ReadResults": [...]
}
```

## 快捷键

| 按键 | 功能 |
|------|------|
| F9 | 开始/停止录制 |
| F10 | StepByStep 模式确认步骤 |
| F11 | 开始/停止回放 |

```

├── 脚本2.json
└── ...
```
