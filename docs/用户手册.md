# 用户手册

## 界面说明

### 左侧：脚本管理

| 按钮 | 功能 |
|------|------|
| 新建 | 创建新脚本 |
| 重命名 | 重命名选中的脚本 |
| 删除 | 删除选中的脚本 |

点击脚本列表中的项可加载该脚本。

### 右侧：主区域

**顶部信息栏：**
- 当前脚本名称
- 录制模式选择（一口气 / 一步一步）
- 快捷键提示
- 录制状态

**控制栏：**
- 录制/停止按钮
- 步骤计数
- 保存/回放按钮

**步骤列表：**
- 显示所有录制的步骤
- 支持多选（Ctrl+点击 / Shift+点击）
- 双击步骤可编辑

**底部操作栏：**
- 新增操作按钮
- 步骤编辑按钮

**日志 + 阅读内容：**
- 左侧：操作日志
- 右侧：阅读窗口内容预览

## 快捷键

| 按键 | 功能 |
|------|------|
| F9 | 开始/停止录制 |
| F10 | 一步一步模式下确认步骤 |
| F11 | 开始/停止回放 |

## 操作类型说明

### 基本操作

| 操作 | 说明 | 需要录制模式 |
|------|------|-------------|
| 点击 | 记录鼠标点击位置 | 是 |
| 输入 | 输入文本内容 | 是 |
| 按键 | 模拟按键（如 Enter, Ctrl+A） | 是 |
| 复制 | 执行 Ctrl+C | 是 |
| 粘贴 | 执行 Ctrl+V | 是 |

### 通用操作

| 操作 | 说明 | 需要录制模式 |
|------|------|-------------|
| 插入 | 在当前位置插入文本 | 否 |
| 等待 | 等待指定毫秒数 | 否 |
| 截图 | 全屏截图保存 | 否 |
| 打开应用 | 选择并打开程序 | 否 |
| 等待应用 | 等待进程启动 | 否 |
| 阅读 | 读取窗口文本内容 | 否 |
| 滚动阅读 | 滚动后读取内容 | 否 |
| 滚动 | 鼠标滚轮滚动 | 否 |

## 使用教程

### 基本录制流程

1. 点击 **⏺ 录制** 或按 **F9**
2. 在目标应用中进行操作
3. 按 **F9** 停止录制
4. 在步骤列表中检查和编辑
5. 点击 **💾 保存** 保存脚本

### 一步一步录制

1. 选择 **一步一步** 模式
2. 开始录制
3. 每完成一个操作，按 **F10** 确认
4. 继续下一个操作

### 编辑步骤

- **双击** 步骤可打开编辑窗口
- 可修改：类型、名称、参数、延时、坐标
- **批量删除**：选中多个步骤后点击"批量删"

### 阅读窗口内容

1. 点击 **📖 阅读**
2. 主窗口自动最小化
3. 切换到要阅读的窗口
4. 3秒后自动捕获并显示内容
5. 可保存为 TXT 或复制到剪贴板

### 脚本管理

- **新建**：创建空脚本
- **保存**：覆盖保存当前脚本或新建
- **加载**：点击脚本列表中的项
- **重命名**：修改脚本名称
- **删除**：删除不需要的脚本

## 注意事项

1. **录制时避免操作录制工具自身**，会被自动排除
2. **回放时保持目标应用可见**，因为使用的是屏幕坐标
3. **不同分辨率/缩放下**，录制的坐标可能不准确
4. **截图保存在** `screenshots/` 目录
5. **脚本保存在** `scripts/` 目录
